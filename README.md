# DNA-RAISE

**Refresh-deferral Authorization via Inspection-to-Service Evidence**

Python source accompanying the DNA-RAISE study of authorization decisions for
long-term DNA archive maintenance. DNA-RAISE reviews a proposed deferral from
an existing maintenance policy using inspection evidence and declared
observation, deterioration and recovery-service models.

## Release scope

This repository contains source code, dependency specifications, usage notes
and source identities. It does not distribute mission-level simulation
records, figure source data, third-party datasets, manuscript files, compiled
figures, private research archives or cluster logs. Plotting and retrospective
analysis programs therefore require their corresponding input files.

The scientific Python files are byte-identical to the preserved research
sources. `SOURCE_PROVENANCE.tsv` records each file's relative source identity
and SHA256. Existing internal names such as `+screen` denote the DNA-RAISE
authorization layer. Historical helper functions remain within their original
modules; they are not additional approved manuscript figures or new results.

## Environments and commands

Use separate virtual environments for the historically different numerical
stacks. V8.7 was recorded with Python 3.12.10, NumPy 2.1.3 and SciPy 1.14.1;
V8.8 with Python 3.9.25, NumPy 1.26.4 and SciPy 1.13.1. Requirements files
specify these direct dependencies. They are not complete operating-system or
transitive dependency locks. The plotting specification combines documented
plotting dependencies; a fresh end-to-end plotting environment has not been
certified by this code-only release.

```bash
python -m venv .venv
# Activate the environment using the command for your operating system.
python -m pip install -r environments/v87-requirements.txt
python Research_Layers/V8_7/v8_7_target_use/analysis_tools/run_v8_7_target_use.py --help
```

The V8.7 driver exposes tuning, negative-control and held-out-test subcommands.
The V8.8 driver exposes design, tuning, test, control and verification commands.
Follow each command's `--help` and supply the required design locks, selections,
input records and output directories. These original scientific drivers may
run substantial simulation or bootstrap work when invoked; publication checks
did not execute them. Do not interpret this source release as a new run of the
frozen experiments or as a self-contained reconstruction of all archived data.
